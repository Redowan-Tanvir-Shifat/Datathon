The Complete Machine Learning Algorithm Selection Sheet

A definitive single-page guide mapping dataset situations to specific ML models.

1. Tree-Based Ensembles (Best for standard Tabular / Spreadsheet Data)

LightGBM (Light Gradient Boosting Machine)

from lightgbm import LGBMClassifier
  • When to use: Large tabular datasets where execution speed and memory optimization are vital. Your default first choice for massive spreadsheets.
  • Why: It uses a leaf-wise tree growth strategy instead of level-wise, making it incredibly fast and efficient while preserving high performance.

XGBoost (Extreme Gradient Boosting)

from xgboost import XGBClassifier
  • When to use: Structured data with complex non-linear correlations where you need maximum predictive precision. Highly competitive.
  • Why: Built explicitly to prevent overfitting through integrated L1/L2 regularization and advanced handling of sparse/missing values.

CatBoost

from catboost import CatBoostClassifier
  • When to use: Tabular datasets containing heavy categorical text data (e.g., countries, zip codes, item categories).
  • Why: Processes categorical data natively using advanced target statistics, removing the need to manually execute One-Hot or Label Encoding.

Random Forest

from sklearn.ensemble import RandomForestClassifier
  • When to use: For immediate baseline scores, handling noisy datasets, or when you haven't cleaned your outliers yet.
  • Why: Uses parallel Bagging to combine hundreds of un-correlated trees. It's incredibly stable and requires almost zero hyperparameter tuning to get a decent score.
2. Linear, Distance, & Classical Models

Logistic Regression / Ridge Classifier

from sklearn.linear_model import LogisticRegression
  • When to use: Clean datasets where variables change linearly (e.g., credit scoring, medical probabilities, or forecasting outside historical bounds).
  • Why: Extremely fast to train, relies on straightforward mathematical weights ($y = wx + b$), and is easy to interpret.

Support Vector Machines (SVM)

from sklearn.svm import SVC
  • When to use: Small but highly complex datasets, or text classification tasks where features are clear but borders are narrow.
  • Why: Uses the "Kernel Trick" to project data into higher dimensions, finding the optimal hyperplane boundary that perfectly separates binary groups.

K-Nearest Neighbors (KNN)

from sklearn.neighbors import KNeighborsClassifier
  • When to use: Recommender systems, simple pattern identification, or anomaly detection where similar data points naturally group together.
  • Why: A lazy learner that makes predictions based purely on spatial distance ($Euclidean\ or\ Manhattan$) between new points and existing points.

Naïve Bayes

from sklearn.naive_bayes import GaussianNB
  • When to use: Real-time text classification, basic spam filtering, or sentiment indexing tasks where processing speed is paramount.
  • Why: Applies Bayes' Theorem under the strict assumption that all input features are independent of one another. Unmatched execution speed.
3. Deep Learning Frameworks (Unstructured Data)

Convolutional Neural Networks (CNN)

import timm / from torchvision import models
  • When to use: Computer Vision datathons providing images, satellite scans, or video arrays.
  • Why: Uses sliding spatial filters to automatically detect edges, shapes, textures, and deep visual features without manual data extraction.

Transformers (BERT, RoBERTa, DeBERTa)

from transformers import AutoModel
  • When to use: Long-form paragraphs, legal documents, chatbot inputs, or intricate language analysis.
  • Why: Employs self-attention mechanisms to look at words bidirectionally in the context of entire sentences, accurately catching nuances like sarcasm and intent.
